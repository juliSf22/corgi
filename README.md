# 🎮 MEMORY TAILS 🎮
*En un mundo donde los recuerdos
toman forma física, Navi, un gato
perdido, despierta en un bosque
espectral lleno de ecos del pasado.
Sin saber cómo llegó allí, descubre
que su propia memoria ha sido
fragmentada en misteriosos cristales
esparcidos por el reino. Para
recuperar su identidad y regresar a
casa, Navi deberá recorrer tierras
olvidadas, sortear trampas
ancestrales y enfrentarse a sombras
del pasado que intentan detenerlo.*
Un juego de plataformas en 2D donde el jugador debe atravesar 4 niveles con enemigos, trampas y desafios para volver a casa.

## 📦 Estructura del proyecto
Este proyecto está dividido en 4 entregas, cada una representa el diseño de un nivel del juego y su implementacion:

| ENTREGA     | DESCRIPCION | ARCHIVO |
|------------|-----------------------|------------------------|
| **1** | Home, instrucciones, creditos | ... |
| **2** | Game over, cambio de nivel, portales | ... |
| **3** | Achievements, AI en enemigos, diseño modos de juego | ... |
| **4** | Feedbacks, funcionalidades de corgi, implementacion modos de juego, boss | ... |

## 🛠️ Cómo instalar
1.	Clona este repositorio o descárgalo como ZIP.
2.	Abre Unity Hub.
3.	Selecciona "Open project" y abre la carpeta raíz donde se encuentran las carpetas Assets y ProjectSettings.
4.	Abre la escena deseada desde Assets/Scenes.
5.	Presiona el botón ▶️ (Play) en Unity para probarlo.

## 📝 Notas finales
A lo largo del desarrollo de Memory Tails, aprendimos a estructurar y planificar un proyecto de videojuego en Unity, desde la idea inicial hasta su implementación técnica. Exploramos temas como scripting en C#, inteligencia artificial básica, diseño de niveles, manejo de escenas, UI, y el uso de assets externos como Corgi Engine.

Uno de los mayores retos fue integrar múltiples funcionalidades en un solo flujo de juego sin romper la experiencia del jugador, especialmente al combinar elementos como enemigos, cambios de nivel, y diferentes modos de juego. Sin embargo, superarlos nos ayudó a entender mejor el proceso de testing, depuración y diseño iterativo.
